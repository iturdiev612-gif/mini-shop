# Mini Shop

Мини-магазин на HTML, CSS и JavaScript (без сборки).

## Возможности
- Каталог товаров из API (dummyjson.com), при ошибке — демо-товары
- Поиск по названию, фильтр по категории, сортировка по цене
- Корзина: добавить, изменить количество, удалить, очистить; сохраняется в localStorage
- Оформление заказа с проверкой формы; заказы сохраняются в localStorage

## Запуск
Откройте `index.html` в браузере или запустите Live Server в VS Code.
